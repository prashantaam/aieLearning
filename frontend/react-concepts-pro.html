Core Concepts

Introduction to React

React is a JavaScript library for building user interfaces through reusable components. It uses a virtual DOM to efficiently update only what changes.

Interactive Preview

Compose UI elements
Hello, React
// Basic component
function App() {
  return <h1>Hello, React</h1>;
}
Note: React focuses on the view layer. You choose the rest of the stack (routing, state management, styling).

JSX

JSX is a syntax extension that lets you write HTML-like code inside JavaScript. It compiles to React.createElement() calls.

Live Example

Dynamic content with expressions
Hello, Developer
function Greeting() {
  const name = "Developer";
  return <h1>Hello, {name}</h1>;
}
Tip: Use curly braces {} to embed any valid JavaScript expression inside JSX.

Components

Components are independent, reusable pieces of UI. Modern React primarily uses function components.

Reusable Components

Instantiate multiple instances
function Button() {
  return <button>Click me</button>;
}

// Reuse as needed
<Button />

Props

Props (short for properties) allow parent components to pass data down to children. Props are read-only.

Passing Data

Update the prop value
Hello, Alex
function Greeting(props) {
  return <h1>Hello, {props.name}</h1>;
}

<Greeting name="Alex" />
Important: Never mutate props inside a child component. Data flows one way — down.

State & useState

State holds data that can change over time. When state updates, React re-renders the component.

Counter Demo

Local component state
0
import { useState } from "react";

function Counter() {
  const [count, setCount] = useState(0);

  return (
    <div>
      <p>{count}</p>
      <button onClick={() => setCount(count + 1)}>+</button>
    </div>
  );
}
Key point: Updating a regular variable does not trigger a re-render. Only state does.

Handling Events

React events use camelCase naming (onClick, onChange) and receive a synthetic event object.

Event Handlers

Click to trigger handlers
function Example() {
  const handleClick = () => {
    console.log("Clicked");
  };

  return <button onClick={handleClick}>Click</button>;
}

Lists & Keys

When rendering lists, provide a stable and unique key prop so React can efficiently track items.

Dynamic List

Items with keys
{items.map(item => (
  <div key={item.id}>
    {item.text}
  </div>
))}
Best practice: Prefer unique IDs over array indexes when the list can be reordered or filtered.

useEffect

useEffect lets you perform side effects after render — data fetching, subscriptions, timers, and cleanup.

Timer Example

Side effect simulation
0

seconds elapsed

useEffect(() => {
  const id = setInterval(() => {
    setSeconds(s => s + 1);
  }, 1000);

  return () => clearInterval(id); // cleanup
}, []);
Dependency array: [] runs once on mount. Omit it to run after every render. Include values to re-run when they change.

Controlled Forms

In controlled components, form state lives in React. The input’s value is driven by state and updated via onChange.

Controlled Input

React as single source of truth
—
const [value, setValue] = useState("");

<input
  value={value}
  onChange={e => setValue(e.target.value)}
/>
<p>{value}</p>
Advantage: Easy validation, formatting, and conditional disabling because React always knows the current value.
