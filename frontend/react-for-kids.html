Concepts

🏠 What is React?

React is like a giant box of magical LEGO blocks for making websites.
You snap colorful pieces together to build buttons, text, pictures and whole pages!

🎮 Try it! Build a tiny page
👋 Hello, friend!
// In React we write components like this:
function App() {
  return <h1>Hello, I am made with React!</h1>;
}
💡 Remember: React helps us build websites by snapping reusable pieces together — just like LEGO!

✨ JSX

JSX looks like HTML but is actually JavaScript with superpowers!
It lets us write beautiful UI code that is easy to read.

👀 See the magic of JSX
Normal HTML
<h1>Hello</h1>
➡️
JSX (React)
<h1>Hello {name}!</h1>

Try changing the name:

Hello, Alex! 🎉
function Greeting() {
  const name = "Alex";
  return <h1>Hello, {name}!</h1>;
}
💡 Curly braces {} let you put JavaScript inside JSX!

🧩 Components

A Component is a finished LEGO creation you can reuse again and again.
Make it once → use it many times!

🧱 Click to create more button components
function HappyButton() {
  return <button>Click me! 😊</button>;
}

// Use it many times:
<HappyButton />
<HappyButton />
<HappyButton />
💡 Components are the building blocks of every React app!

🎁 Props

Props are like gifts you give to a component.
The component opens the gift and uses what’s inside!

🎁 Give a gift (prop) to the robot
🤖
Hello, Emma! 💖
function Hello(props) {
  return <h1>Hello, {props.name}!</h1>;
}

<Hello name="Emma" />
💡 Props are read-only. The child component cannot change them — only the parent can!

🔢 State & useState

State is like a scoreboard that can change.
When the number changes, React automatically updates the screen!

🎮 Live Counter (this is State!)
0
import { useState } from "react";

function Counter() {
  const [count, setCount] = useState(0);

  return (
    <div>
      <h2>Count: {count}</h2>
      <button onClick={() => setCount(count + 1)}>Add</button>
    </div>
  );
}
💡 Normal variables don’t update the screen. State does!

👆 Handling Events

An Event is when something happens — click, type, hover...
You tell React: “When this happens → do that!”

🎯 Click the buttons and see what happens!
function ClickMe() {
  const sayHi = () => alert("Hi there! 👋");
  return <button onClick={sayHi}>Click Me</button>;
}
💡 In React we write onClick (camelCase) instead of onclick.

🌤️ Conditional Rendering

Show something only if a condition is true.
Like: “If sunny → show sun. If rainy → show umbrella.”

🌦️ Toggle the weather!
☀️
It's sunny outside!
function Weather({ isSunny }) {
  return isSunny
    ? <h2>☀️ Sunny day!</h2>
    : <h2>🌧️ Rainy day!</h2>;
}
💡 We use the ternary operator ? : or && for this.

📋 Lists & Keys

When showing many items, each one needs a special name tag (key)
so React doesn’t get confused!

🧸 My Toy Collection (each has a Key)
{toys.map(toy => (
  <div key={toy.id}>
    {toy.emoji} {toy.name}
  </div>
))}
💡 Always give a unique and stable key (usually an id). Never use the array index if the list can change order!

⏱️ useEffect

useEffect is a helper that runs after the picture is drawn.
Perfect for timers, loading data, or cleaning up!

⏰ Live Timer (runs with useEffect idea)
0

seconds

useEffect(() => {
  const id = setInterval(() => {
    setSeconds(s => s + 1);
  }, 1000);

  return () => clearInterval(id); // cleanup
}, []);
💡 The empty array [] means “run only once when the component appears”.

📝 Controlled Forms

In a controlled form, React is the boss of the input box.
Whatever you type is stored in state so React always knows the value.

✍️ Type something — React mirrors it instantly!
✨ Your text will appear here ✨
const [name, setName] = useState("");

<input
  value={name}
  onChange={(e) => setName(e.target.value)}
/>
<p>You typed: {name}</p>
💡 This is called a “controlled component” because React controls the value.
